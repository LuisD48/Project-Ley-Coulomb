# Project-Ley-Coulomb-Campo-Electrico

## Simulador de Fuerza y Campo Eléctrico

Un simulador web interactivo diseñado para calcular e ilustrar la Ley de Coulomb y los Campos Eléctricos entre dos cargas puntuales. 

### Características

* **Cálculos precisos:** Calcula la magnitud de la fuerza eléctrica y el campo eléctrico (E1 y E2) generado por cada partícula.
* **Visualización en tiempo real:** Animación de los vectores de fuerza (atracción y repulsión) que reaccionan automáticamente a los signos de las cargas ingresadas.
* **Notación científica:** Formateo automático de los resultados matemáticos para una lectura académica estandarizada.
* **Interfaz intuitiva:** Diseño web limpio, responsivo y con funcionalidad para limpiar los datos para nuevas pruebas.

### Tecnologías utilizadas

* **HTML5:** Estructura semántica del simulador y el panel teórico.
* **CSS3:** Diseño responsivo utilizando Flexbox y animaciones de transformaciones espaciales.
* **JavaScript (Vanilla):** Lógica matemática, validación de datos y manipulación del DOM (sin librerías externas).
